# M0 workstream plan — foundations

## Goal
Publish the initial source audit, charter, PRD, architecture, ADRs, cost model, security model, testing gates, upstream tracking and agent workflow.

## Steps
1. Verify correct repository owner and Contents/Issues write permissions.
2. Commit documents in one reviewable baseline, without importing external licensed code.
3. Create distinct GitHub issues for MVP/M1, add-on parity/M2, BYOC/M3, hosted compute/M4 and verification/M5.
4. Add reusable issue template and PR checklist, then plan a baseline CI job.
5. Check that every Markdown link resolves and all status claims are honest.

## Exit
Docs available at main branch URLs; issues created and linked; no claims of completed build or deploy.

## Rollback
Revert docs commit if inaccurate; retain issue discussion and correct publicly.
