# Browser limitation ledger

Evidence levels: **declaration** is provider metadata, **probe** is a browser prediction, **playback** requires advancing delivered frames. None implies native-player or physical-output success. Diagnostics do not fetch media, inspect extensions or recommend disabling protection globally. Unknown delivery is never a proven broken provider.

For each new limitation record engine/backend + OS/version (unknown explicitly), fixture digest or immutable access-provenance receipt, evidence level, symptom, remedy and retest. Never record signed URLs, titles, credentials or header values. [Contract/evidence](plans/issues/issue-150.md).
